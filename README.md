# NEON — Web Calculator

A modern, responsive web-based calculator developed using **HTML, CSS, and JavaScript**. The application features a sleek dark interface with neon cyan accents, interactive buttons, and keyboard support.

This project demonstrates fundamental web development concepts, including HTML structure, CSS styling, event handling, JavaScript functions, and DOM manipulation.

## ✨ Features

- **Basic Arithmetic Operations:** Addition, subtraction, multiplication, and division.
- **Interactive Calculator:** Number buttons from 0 to 9, arithmetic operators, clear (`C`), delete (`DEL`), decimal point, sign change, and equals (`=`).
- **JavaScript Functions:** Separate functions implement each arithmetic operation.
- **Keyboard Support:** Perform calculations using keyboard numbers, operators, Enter, Backspace, and Escape.
- **Real-Time Display:** Shows the current input, mathematical expression, and calculated result.
- **Error Handling:** Handles division by zero and invalid calculation states.
- **Hover Effects:** Buttons respond visually to mouse interactions.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Modern UI:** Dark theme, neon cyan highlights, subtle animations, and a clean calculator layout.

## 🛠️ Technologies Used

- **HTML5** — Structures the calculator interface.
- **CSS3** — Provides styling, responsive layouts, hover effects, and animations.
- **JavaScript (ES6+)** — Implements arithmetic operations, keyboard controls, event handling, and display updates.
- **Google Fonts** — Space Grotesk and DM Mono typography.

## 🚀 Getting Started

### Prerequisites

A modern web browser is sufficient to run the calculator. Visual Studio Code and the Live Server extension are optional.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/WebCalculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd WebCalculator
   ```

3. Open `index.html` in your browser, or use Live Server in Visual Studio Code.

Replace `YOUR-USERNAME` with your actual GitHub username.

| Key | Action |
|---|---|
| `0–9` | Enter a number |
| `+` | Addition |
| `-` | Subtraction |
| `*` or `x` | Multiplication |
| `/` | Division |
| `.` | Decimal point |
| `Enter` or `=` | Calculate the result |
| `Backspace` | Delete the last digit |
| `Escape` or `Delete` | Clear the calculator |

## 🌐 Deployment

The application can be hosted for free using GitHub Pages.

1. Open the repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Under Build and deployment, select **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder.
5. Click **Save**.
6. Once deployment is complete, open the published website using the URL provided in the Pages settings.

The website URL will follow this format:

`https://velsrinithi.github.io/WebCalculator/`
